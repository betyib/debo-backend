# Debo Backend

Backend API for the Debo project management application.

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JWT Authentication
- BCrypt

## Features

- User authentication
- JWT protected routes
- Project CRUD operations
- Task CRUD operations
- Task status updates
- Kanban board support
- Profile editing
